# yard-broker B0: ambiguity register

Every call the broker makes or serves across a process boundary, its outcome
classes, and the rule the broker follows when it cannot tell which one
happened. Format and rules: casselc/observability AMBIGUITY.md and
model/TEMPLATE.md (copies in research/agent-platform/ref-observability/):
**done** (happened, nothing in flight can undo it), **not done** (did not
happen, nothing in flight can make it happen), **unknown** (everything else;
the default). Every unknown needs a settle bound, a resolving observation and
a caller rule (wait, verify, fence, idempotent retry).

Code: `internal/broker`, `cmd/yard-broker`. Tests: `go test -race
./internal/broker/ ./cmd/yard-broker/`. Mutants: `tools/broker-mutants.sh`
(run under `-race`; 74 after fix round 2 closeout, see STATE.md). The broker's only
module dependency beyond the standard library is `golang.org/x/sys/unix`
(secret reads anchored at a directory fd), already a direct dependency of
yard in go.mod; no module was added.

Fix round 1 (reviews by GPT-6.1 and GLM-5.3, 2026-10-07) changed rows B1,
B3, B4, B7, B8 and B10 and added B11–B15. Fix round 2 (second-pass reviews)
rewrote B1, B5, B7, B8, B10, B11, B12, B13 and B15.

## No new Quint model

The broker's only stateful ambiguous call is the credential mint, and it is
already modelled, with this broker as a party, in `spec/warden` (broker
process `broker`; rules `RetryRule = NextSlot`, `trustClaimed`, `rawForward`,
`forwardJwt`, `epochCheck`; properties P4b `atMostOneMintPerSlot`, P7
`sandboxOnlyOwnCreds`, P8 `brokerHonoursCurrentEpoch`). The halo turn is
modelled on the server side in halo-flash `spec/scheduler` (mutant
`noIdempotency`). The broker never retries anything, so it has no caller
rule left to choose. The warden model's scripted runs for the broker's rules
were re-run on this tree (quint 0.32, `quint test` only):
`blindRetryBreaksTest`, `trustClaimedBreaksTest`,
`staleEpochAcceptedBreaksTest`, and on `designAws` `lostAnswerRemintTest`,
`expiredJwtRefusedTest`, `resumeAckTest`, `brokerRestartPullTest`: all pass.

Two things fix round 1 added are **not** in that model and are argued here
instead: the allocation incarnation (the model's tap is a fixed sandbox; real
addresses are reused) and the registry's serial and lease (the model's broker
pulls epochs from yard-ctl directly). If B1 replaces the file registry with
a yard-ctl channel, that channel's notice/ack belongs in `spec/warden`
(`act_epoch`, `act_epoch_ack` already exist).

Model to code:

| `act_exchange` / `act_assume` (one JWT, sent once) | `credStore.start`: one `Minter.Mint` per sandbox in flight, fresh `MintID` (yard-mint tag); `MintRequest.Begin(jwtExp)` is the gate before anything reaches the cloud STS |
| `act_timeout`, `act_err` with `NextSlot` (mutant `blindRetry`) | the store's own timer settles a begun attempt at `fence = jwtExp + Skew` whatever the minter does; no new mint before it (`blindRetry`, `fenceIgnoresJWT`) |
| late `Creds` adopted unless stale | an answer before the fence is checked by `refuse` (generation, link, epoch, tag, TTL); after the fence it is discarded (an orphan for the reconciler) |
